# Aachen-project

This repository includes papers and manuscripts for experimental setup

## ODMR click-to-measure viewer

`ODMR/` contains a VS Code-ready app that live-views a Thorlabs CMOS
camera and, on click, sweeps a Windfreak SynthHD microwave generator to
measure the ODMR spectrum of an NV-diamond ensemble at that spot. See
[`ODMR/README.md`](ODMR/README.md) for setup and usage.
