# Search notes

Search date: 2026-07-12 (Asia/Tokyo)

## Name normalization

- "Andrzej Grezechnik" was normalized to **Andrzej Grzechnik**.
- "Martin Meren" was normalized to **Martin Meven**, based on the exact coauthor set in the DAC neutron-diffraction papers.

## Representative queries

- `"Andrzej Grzechnik" "diamond anvil cell"`
- `"Karen Friese" "diamond anvil cell"`
- `"Lars Peters" "diamond anvil cell"`
- `"Martin Meven" "diamond anvil cell"`
- author name + `DAC`, `high pressure single-crystal diffraction`, `Raman`, `neutron diffraction`
- exact-title searches against publisher sites, IUCr, JuSER/Forschungszentrum Jülich, RWTH Publications, DESY PubDB, ORA and PubMed.

## Inclusion rule

A paper was included only when DAC-based sample measurement was explicit in an abstract, full text, methods section, or open supplementary material. High-pressure synthesis in a multi-anvil press without DAC measurement was not sufficient.

## Access rule

Only PDFs available as open-access publisher copies or institutional/author repository copies were downloaded. Other records are link-only.
