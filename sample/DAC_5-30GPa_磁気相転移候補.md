# DAC測定候補：5–30 GPaで磁気相転移を示す試料

## 1. 結論

Andrzej Grzechnik、Karen Friese、Lars Peters、Martin MevenらのDAC関連論文で扱われた試料のうち、**5–30 GPaの範囲内で磁気秩序の明確な変化が実験的に確認されている有力候補は、現時点では β-Na\(_{0.33}\)V\(_2\)O\(_5\) である。**

推奨測定範囲は次のとおり。

\[
P = 5\text{–}10\ \mathrm{GPa}
\]

特に、反強磁性長距離秩序が消失する臨界圧力近傍として、

\[
P = 7\text{–}9\ \mathrm{GPa}
\]

を細かく測定することが望ましい。

---

## 2. 第一候補：β-Na\(_{0.33}\)V\(_2\)O\(_5\)

### 2.1 磁気・電子状態

β-Na\(_{0.33}\)V\(_2\)O\(_5\) は常圧で、低温において反強磁性長距離秩序を示す。

代表的な転移は以下である。

- 電荷秩序・金属絶縁体転移：\(T_{\mathrm{CO}}\approx135\ \mathrm{K}\)
- 反強磁性転移：\(T_{\mathrm{N}}\approx22\text{–}25\ \mathrm{K}\)

高圧 \(^{51}\)V-NMR測定では、反強磁性長距離秩序が圧力とともに維持された後、

\[
P_{\mathrm{c}}\approx8\ \mathrm{GPa}
\]

付近で消失することが報告されている。

したがって、**5–30 GPaという指定範囲内に明確な磁気相境界を持つ**。

### 2.2 圧力相図上の特徴

約8 GPa近傍では、以下の現象が競合する。

1. 反強磁性長距離秩序の消失
2. 電荷秩序の抑制
3. 金属化
4. 圧力誘起超伝導相の出現

このため、測定信号の変化を磁気秩序だけに帰属させるには、抵抗測定、X線回折、NMRなどの既報相図との照合が必要である。

### 2.3 推奨圧力点

| 測定区間 | 目的 |
|---|---|
| 5–6 GPa | 反強磁性相側の基準測定 |
| 6–7 GPa | 臨界領域への接近 |
| 7–9 GPa | 磁気秩序消失の詳細測定 |
| 9–10 GPa | 非磁性・金属／超伝導側の基準測定 |
| 10 GPa以上 | 高圧相の安定性および構造変化の確認 |

臨界領域では、0.2–0.5 GPa程度の圧力刻みが望ましい。

### 2.4 DAC測定との対応

Grzechnikらは β-Na\(_{0.33}\)V\(_2\)O\(_5\) の単結晶構造を、室温で約19 GPaまでDAC内で測定している。

ただし、この構造研究自体は磁気転移を直接測定したものではない。約8 GPaでの反強磁性秩序消失は、別研究の高圧NMRによって確認されている。

したがって、次の2点が既報によって個別に確立している。

- 試料をDAC内で少なくとも約19 GPaまで測定可能
- 約8 GPaで磁気秩序が消失

---

## 3. 実験上の注意点

### 3.1 反強磁性体の漏洩磁場

β-Na\(_{0.33}\)V\(_2\)O\(_5\) は主として反強磁性体であるため、理想的なバルク内部では正味磁化が小さい。

NV-ODMRなどで局所磁場を測定する場合、信号源として以下が重要になる。

- 試料表面
- 磁区境界
- 結晶欠陥
- 圧力勾配が存在する領域
- canted antiferromagnetic成分
- 相共存領域

試料全体の一様磁化を測定する設計よりも、局所磁場分布や線幅変化を追跡する設計の方が適している可能性がある。

### 3.2 圧力媒体

7–9 GPaで磁気相境界を測定する場合、非静水圧成分によって転移が広がる可能性がある。

可能な範囲で静水圧性の高い圧力媒体を使用し、ルビー蛍光または別の圧力マーカーによって圧力分布を評価する必要がある。

### 3.3 構造相との分離

β-Na\(_{0.33}\)V\(_2\)O\(_5\) では高圧下で構造変化も報告されている。磁気信号の変化を評価する際には、次を区別する必要がある。

- 磁気秩序の消失
- 電荷秩序の消失
- 金属絶縁体転移
- 結晶構造変化
- 超伝導転移

可能であれば、同一圧力系列でX線回折またはラマン分光を併用することが望ましい。

## 4. 補助候補と除外理由

| 試料 | 5–30 GPaで確認された主な変化 | 判定 |
|---|---|---|
| β-Na\(_{0.33}\)V\(_2\)O\(_5\) | 約8 GPaで反強磁性長距離秩序が消失 | **第一候補** |
| β-Li\(_{0.33}\)V\(_2\)O\(_5\) | 約9 GPa、11 GPaで構造相転移 | 磁気相転移としては未確認 |
| β-Ag\(_{0.33}\)V\(_2\)O\(_5\) | DAC内で構造安定性を評価 | 5–30 GPaの磁気相境界の直接証拠が不足 |
| Mn\(_5\)Si\(_3\) | 室温で少なくとも24.2 GPaまで構造安定 | 高圧磁気相境界が未確立 |
| MnFe\(_4\)Si\(_3\) | 強磁性転移温度が圧力で低下 | 主な実測圧力が約1 GPaで、指定範囲外 |
| CrAs | 約0.7 GPaで磁気秩序が抑制 | 指定範囲より低圧 |
| α-V\(_6\)O\(_{13}\) | 少なくとも9.4 GPaまで基本構造が安定 | 圧力誘起磁気相転移の直接報告なし |
| α-V\(_2\)O\(_5\) | 約7.3 GPa以上で不可逆的アモルファス化 | 磁気相転移ではない |
| V\(_{0.92}\)O\(_2\) | 数GPa域で構造・電子相転移 | 長距離磁気秩序の相転移とは断定できない |
| Fe(PM–BiA)\(_2\)(NCS)\(_2\) | 圧力誘起high-spin–low-spin転移 | 主な転移圧力が1 GPa未満 |

## 5. 推奨する初期測定計画

### 圧力系列

\[
5,\ 6,\ 7,\ 7.5,\ 8,\ 8.5,\ 9,\ 10\ \mathrm{GPa}
\]

### 優先的に評価する観測量

1. 局所磁場またはODMR共鳴周波数
2. ODMR線幅
3. ODMRコントラスト
4. 磁場分布の空間的不均一性
5. 加圧・減圧時のヒステリシス
6. 試料周辺の圧力分布
7. 電気抵抗または既報相図との対応

### 成功判定

約8 GPaを挟んで再現性のある磁気信号変化が現れ、構造変化または圧力勾配だけでは説明できないことを確認する。

## 7. 最終評価

5–30 GPaの圧力範囲に限定した場合、収集済みDAC論文の試料群では、

\[
\boxed{\beta\text{-Na}_{0.33}\text{V}_2\text{O}_5}
\]

が最も根拠の強い候補である。

特に、**7–9 GPaにおける反強磁性長距離秩序の消失**を狙う測定計画が妥当である。一方で、反強磁性体のため漏洩磁場が小さくなる可能性があり、NV-ODMRでは磁区境界、欠陥、相共存領域および線幅変化を利用した検出設計が重要になる。
