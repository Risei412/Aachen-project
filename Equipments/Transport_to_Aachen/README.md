# DAC-NV 実験系 ドイツ移設 — 輸送・輸出管理資料

DAC-NV 実験系をドイツ（アーヘン）へ移設するにあたり、航空輸送の可否分類、
該非判定の準備、発送手段の選定、精密機器の梱包までをまとめた資料一式。

## ファイル

| ファイル | 内容 |
|---|---|
| `DACNV_Equipment_List_1.xlsx` | 元データ（機材・部品購入構成表）。スクリプトの入力 |
| `DACNV_Equipment_List_輸送分類.xlsx` | 4分類表・再購入リスト・重要品目メモ |
| `DACNV_輸出手続き_発送_振動対策.xlsx` | リードタイム・発送手段比較・梱包・チェックリスト・該非判定書の集め方 |
| `DACNV_Equipment_List_輸送分類.pdf` | 上記の印刷・配布用 PDF（7ページ） |
| `DACNV_輸出手続き_発送_振動対策.pdf` | 上記の印刷・配布用 PDF（8ページ） |
| `build_transport_classification.py` | 1つ目の xlsx の生成スクリプト |
| `build_export_procedure.py` | 2つ目の xlsx の生成スクリプト |

## シート構成

**DACNV_Equipment_List_輸送分類.xlsx**

- `機材一覧` — 元データそのまま（無改変）
- `輸送分類` — 全53品目を ①発送のみ ②機内持込のみ ③両方可 ④両方不可 に分類。
  機内持込／預入／発送の可否、危険物区分、輸出令の想定項番、要確認フラグ、判断理由、推奨を併記
- `再購入リスト` — A: 発送品（買い直し対象35件）／B: 借用品3件／C: 現地調達推奨／D: 持参品14件（参考）
- `重要品目メモ` — レーザーとマイクロ波アンプの機内持込に関する評価と準備物

**DACNV_輸出手続き_発送_振動対策.xlsx**

- `判定リードタイム` — 該非判定にかかる時間を遅い順に。国内での輸出手続きの論点
- `発送サービス比較` — クーリエ／フォワーダー／EMS／ATAカルネ／別送品の比較
- `振動対策・梱包` — 手荷物で運ぶ精密機器の振動・衝撃対策
- `時系列チェックリスト` — 渡航日 D から逆算した作業順
- `該非判定書_手順` — 品目の4群への仕分け、請求メールの英文テンプレ、受領書類の検収、代替ルート
- `該非判定書_追跡表` — 請求状況を管理する記入用トラッカー（ステータスはドロップダウン）

## 再生成

```
pip install openpyxl
python build_transport_classification.py
python build_export_procedure.py
```

どちらもスクリプトと同じディレクトリに xlsx を出力する。
分類の内容はスクリプト内のテーブル（`build_transport_classification.py` の `T`、
`build_export_procedure.py` の各リスト）を直せば反映される。

PDF は Excel の「PDFとして保存」か、LibreOffice で次のように出力する。

```
soffice --headless --convert-to pdf DACNV_Equipment_List_輸送分類.xlsx
```

## 印刷について

列数の多い表を A4 に押し込むと実効フォントが 4〜5pt になり印刷しても読めないため、
シートごとに用紙を分けている。

| 用紙 | シート |
|---|---|
| A3 横 | 機材一覧、輸送分類、判定リードタイム、発送サービス比較、該非判定書_追跡表 |
| A4 横 | 再購入リスト、振動対策・梱包、時系列チェックリスト |
| A4 縦 | 重要品目メモ、該非判定書_手順 |

表形式のシートは改ページ後も見出し行が繰り返し印刷される。
フッターにページ番号と印刷日が入る。実効フォントは 8〜9.7pt
（`機材一覧` のみ元の列幅が広いため 7.3pt）。

分類・要確認フラグ・条件付き書式は色で区別しているため、
申請資料として配る場合はカラー印刷を前提にすること。

行の高さは折り返しの自動調整に任せている箇所がある。
列幅を変えたときは PDF に出して本文が切れていないか確認すること。

## 免責

輸出令別表第1の項番はいずれも公開仕様からの推定であり、該非判定の最終結論ではない。
実際の申請にはメーカー発行の該非判定書（パラメータシート）を取得し、
所属機関の輸出管理担当部署の確認を受けること。
航空会社の持込可否も最終的には当日の運送人および保安当局の判断による。
単価欄は見積が無いため空欄（「要見積」）としてあり、推測値は入れていない。
